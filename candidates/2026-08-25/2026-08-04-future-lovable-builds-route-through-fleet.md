# New Lovable Projects Should Be Built With the Fleet, Not Lovable's Own Defaults

## Body

Abad set a standing instruction: future Lovable projects should be built with the STAG Fleet involved, and the Fleet should pick the tech stack, rather than the project silently defaulting to whatever Lovable's own project creation flow picks. No concrete stack decision has been made yet; this is a routing rule for how future Lovable builds should start, not a finished spec.
