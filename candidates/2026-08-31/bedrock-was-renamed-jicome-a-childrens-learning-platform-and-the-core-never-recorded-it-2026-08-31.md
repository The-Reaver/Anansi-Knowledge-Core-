# BEDROCK is Jicome, a children's learning platform — a real product the Knowledge Core does not know exists

## Body

`governance/STAG-Naming-Standard-v1.0.md` (line 60) records: **BEDROCK → Jicome** — the
real, live product name for the **children's learning platform**, not internal jargon. It
was deliberately kept out of the mythology rename rule's blanket sweep once that
distinction surfaced on 2026-08-11. The name also appears in `publish-handoff-v1.0.md` as
a trigger word, and the exception is taught as a worked example in
`curriculum/completed/FLT-200-Batch-FLT05.md`.

**None of this is in the Knowledge Core.** Searching the Core for "Bedrock" returns only
AWS Bedrock fine-tuning. A session obeying the standing "recall before you guess" rule will
search the Core, find nothing, and confidently report that no such product exists — which
is exactly what happened, with confidence, before a repo-wide grep corrected it.

This is a **capture gap, not a knowledge gap**: the fact was never lost, it was only never
written where the retrieval rule points. Governance files and curriculum are not searched
by the Core's meaning-search.

Unresolved: whether the operator's remembered "Bedrock as a personal learning dashboard" is
the same idea that became Jicome with the audience shifted to children, or a separate thing
that shared a codename. That distinction decides whether there is an existing product to
extend or a fresh build.
