# STARS/DREAMS is fully designed and stalled on one unanswered routing question from 2026-08-08

## Body

Audited 2026-08-31 as one of six dormant areas. The design is **complete and well
documented**: STARS is the curriculum — an ordered roadmap of skills cut into slices, each
with a proof gate. DREAMS is the tracker — a live scorecard of level per skill plus one
composite index. The Augustin pattern, generalised so every key fleet agent trains the same
way, with a resume-from-repo protocol so a fresh chat picks up where the last one stopped.

Supporting material exists: an Augustin DREAMS tracker artifact registration, a TYR
curriculum (lead Breaker / Security Auditor), the ADLC gameplan, and a graduation-bar /
Breakers-gauntlet design.

**What blocks it is a single unresolved question.** A proposed 9-Gate model may or may not
replace the ratified STARS/DREAMS TRL 1–9. It went to the Brain Trust on 2026-08-08 and no
resolution is recorded. Until that is answered, extending the pattern to other agents risks
building on a model that is about to be superseded — so nothing extends, and the design
sits.

Also flagged: the original `STARS.docx` is in
`_to_delete/fleet-lore-superseded-2026-08-09/`. If any part of it is not yet reproduced in
the tracked curriculum, deleting that folder loses it.

**Action this implies:** resolve the 9-Gate routing question first. It is one decision
gating an entire designed system, which makes it the cheapest unblock of the six areas.
