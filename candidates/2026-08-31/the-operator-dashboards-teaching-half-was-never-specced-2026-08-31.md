# The operator's dashboard was specced to explain the fleet, never to teach him the craft — and only the second half is a real gap

## Body

Audited 2026-08-31. The dashboard concept exists twice over, both times as the *explaining*
half:

- A fleet dashboard spec, **approved and pending release** — an "ever growing" dashboard
  stating **plainly** what each agent does and how sure the fleet is about it, with honest
  proof-strength.
- A fleet dev dashboard **assigned to Antigravity** — roster, skills, skill tree, proof and
  gates, decay watch, each item traced to a real source file and honest about proven versus
  claimed.

**Not found anywhere: the half that teaches the operator development, SDLC mastery,
deployment and cybersecurity.** The approved spec explains the fleet; it does not teach the
craft. That half appears never to have been specced at all.

This is the one area of the six that is a **genuine gap rather than a stalled pipeline**,
and the two need different responses. Five areas need their last step connected. This one
needs a brief written from scratch — there is nothing dormant to revive.

Related and unresolved: the operator recalls "Bedrock" as a personal learning dashboard,
while the governance record has BEDROCK renamed to Jicome, a children's learning platform.
Whether those are one idea whose audience shifted, or two things sharing a codename,
decides whether this is an extension or a fresh build.
