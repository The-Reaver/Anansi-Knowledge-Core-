# Anansi Gets a Scoped, Time-Boxed Slice Running Parallel to GEO, Not Ahead of It

## Body

The Brain Trust ruled that Anansi/Jeremy's build gets a scoped parallel slice, not a full jump ahead of the existing build order. Scope is limited to the ledger schema plus the capture API, running parallel with GEO's hardening work rather than ahead of it, with a 5-day timebox set by Amadeus; if it slips past that, it reverts to its original queue position behind CI validation. Four conditions were attached: zero of Abad's own bandwidth gets diverted from GEO (Elijah), Oluwole's diagnostic on Augustin gets delivered alongside it, one real write-then-reuse proof happens before the full Phase 2 knowledge base is promoted in priority (Jasiah), and GEO/CI start emitting ingestible lesson output now rather than waiting for the ledger to exist (Bink).
