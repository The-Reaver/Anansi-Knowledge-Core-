# What counts as "decided" enough to become a note: a real decision, ruling, ratified rule, concrete build outcome, or explicit correction/finding

## Body

This is the bar already applied when writing an earlier session's 22 notes, named explicitly here so it stays consistent going forward for any future harvesting or historical-diagnostic work. Exploratory reasoning or brainstorming that never converged to an actual outcome does not get its own note; only the resolution, if one was reached, does.
