# Weight-watch proxy threshold set: roughly 15 substantial tool calls, or 3 subagent dispatches, or 2 large file/document reads combined with either

## Body

A concrete starting default for Mandate 10's proactive handoff trigger, since no live token or context count is available to Claude mid-conversation. Once a session crosses this heuristic bundle it should self-check and consider offering a Knowledge Core handoff. This is a starting number, not a fixed law — it can be tightened or loosened once its behavior in practice is observed.
