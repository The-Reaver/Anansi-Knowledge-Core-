# A living memory system that accumulates wrong or stale facts is worse than no memory system — it reads as authoritative and is not

## Body

Every entry into Knowledge Core needs a real source, a real date, and a real way to revise an entry found wrong, rather than letting it sit uncorrected once buried in a system nobody double-checks. This mirrors the discipline settled on for legal/compliance facts specifically. Building memory without building the correction path builds the exact failure mode Knowledge Core exists to prevent.
