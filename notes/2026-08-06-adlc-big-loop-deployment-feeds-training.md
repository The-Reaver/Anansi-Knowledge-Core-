# The ADLC Big Loop: deployment is not the end — a deployed agent's real build requests become the next, harder training

## Body

A deployed agent taking real build requests has each real job captured as notes, which becomes the next, harder training, which feeds back into the Engine. Real work and training become the same loop, so the fleet compounds instead of plateauing once agents graduate.
