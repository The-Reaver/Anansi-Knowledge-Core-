# Build a new agent only when there is a real job for it — every agent needs a defined role, a curriculum, and must prove useful; no agents for their own sake

## Body

Applies fleet-wide. For example, TYR needed its one job defined before being considered truly born. This keeps the roster lean and prevents role clutter.
