# Fleet interview-and-audit governance for the CIPP/E redesign phase, and the lean agent-graduation principle

## Body

## Phase
- After v1: conduct research, redesign the screens, fold in the specialist agent so it serves the user effectively and efficiently. The system is put up for scrutiny: the fleet audits what was built, and the operator conducts an intuitive interview with the user that the fleet drives, to keep improving the app.

## Question routing (by subject matter, app area, and expertise)
- Elijah asks his own specific questions. Other members weigh in depending on the subject matter, which part of the app it touches, and who holds the relevant expertise.
- Architecture: Celestina, always, unless she births a specialist agent for a specific question, in which case that extracted agent owns it.
- Lower-level questions: Augustin.
- Higher-level questions: Augustin for now, until he graduates a specialist (for example a React Native agent, an HTML agent, a CSS agent, a test writer, an app breaker), and then that specialist takes those questions.
- This routing pattern holds across the whole fleet.

## Agent-graduation principle (lean)
- Graduate an agent only when it makes sense, extracted from a parent agent's role (the way Augustin will). No mandate that all agents must graduate many agents. Keep the roster lean and no mess; each specialist earns its existence through a real, repeated need.

## Ties
- Audit side connects to the Breakers gauntlet (TYR) and AJ certification. The specialist neurodivergent agent (Orlok specialized or new, operator to name) participates on the accessibility and neurodivergent surface.
