# Required partner-document message, report depth scales with Knowledge Core richness (the compounding investment case)

## Body

## The message (must appear in the partner documents)
Report depth is a function of how much validated material the Knowledge Core holds. A rich, lawyer-validated Core produces a long, deep report from the same Generate button. A thin Core produces a short one. In the demo the sample data is small, so the generated report is real but short, not a literal 24 pages. Once the Core is live and full with all the rules and citations the lawyer validated, the same button produces the deep, 24-page-caliber document, because there is far more validated content to assemble and cite.

## Why it matters (the argument for the partner)
Every dollar and hour invested in the Core and its maintenance makes every future report and audit deeper and better, at no extra work per report. The investment compounds. This is the justification for the agents, the Knowledge Core, the tools, and the software spend.

## Where it goes
- GEO Suite document (task 10): explain that the product's output depth grows with the Core.
- Knowledge Core document (task 13): the compounding mechanism in depth.
- Finances document (task 14): underpins the savings and ROI story.

## The three partner documents (confirmed separate)
1. GEO Suite document, in-depth, every point, do not miss any.
2. Finances document, all costs and tools, three assistants' salaries, savings vs a traditional team; operator salary omitted.
3. Knowledge Core document, effectiveness, build, origin, compounding, maintenance agents, lawyer role.
