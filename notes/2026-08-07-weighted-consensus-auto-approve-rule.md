# Auto-approve rule: accept a note automatically only if N agents' Wilson-weighted votes agree >= 2/3 AND the note clears the quality bar — otherwise, or for any high-impact rule, it goes to human review

## Body

Collect votes from N agents, weight each by its Wilson-scored reliability. Auto-accept only if weighted agreement >= 2/3 AND the note clears the note-quality bar. Below that threshold, or for any high-impact rule regardless of agreement, the note routes to the human review queue instead of auto-accepting.
