# The anansi-promote skill that defines the real candidate-review rubric is packaged as an unregistered zip file, not an invokable project skill, and must be manually extracted and followed

## Body

The anansi-promote skill, which defines the real five-dimension rubric for reviewing Knowledge Core candidate notes, is packaged as a zip file at the operator's local Claude skills folder and is not registered in the project's invokable skill list. It must be manually located, extracted, and read (SKILL.md plus references/rubric.md) and followed by hand rather than invoked through the normal Skill tool. A future session doing this same candidate-review work needs to know to look for it this way rather than assuming a slash-command or registered skill exists.
