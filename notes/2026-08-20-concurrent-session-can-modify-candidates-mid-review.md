# A separate, concurrent process can modify the Knowledge Core's candidates folder mid-review, so a folder listing should be re-verified rather than trusted from an earlier snapshot

## Body

While reviewing the Knowledge Core's needs-work candidate folder, four of its nineteen originally-listed files disappeared partway through the review. Investigation confirmed no data was lost: a separate, concurrent process, unrelated to the reviewing session, had independently already promoted those four files directly into the permanent notes folder during the same time window. The lesson for any future review session is that a candidate folder's listing should be re-verified rather than trusted from an earlier snapshot, since another process may be operating on the same repository concurrently.
