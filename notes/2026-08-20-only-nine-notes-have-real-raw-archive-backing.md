# Only nine notes in the entire Knowledge Core repository have a real, honest archived-transcript file available to cite as provenance

## Body

Investigating what it would take to close the 151-note schema gate found that the entire repository contains exactly nine notes with real, honest archived-transcript backing available to cite: three files directly under the raw archive directory, one more inside a dedicated pipeline knowledge room, and five more inside a dedicated Lords of Cian knowledge room, each separately checked and found to already have correct, working provenance fields pointing at real transcript files. There is no unused archived transcript material anywhere in the repository that the other 151 non-compliant notes could honestly cite; the underlying evidence those notes would need to comply simply does not exist, which means the gap cannot be closed by adding missing fields, only by a policy decision or by capturing real transcripts going forward.
