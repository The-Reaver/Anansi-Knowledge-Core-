# Explicit rejection is recommended for the seven candidate notes that confuse the GEO Suite's own Knowledge Core with the fleet-wide Anansi Core, but the decision was left open for the operator rather than acted on directly

## Body

The seven candidate notes found to confuse the GEO Suite product's own Knowledge Core with the fleet-wide Anansi Core were left unpromoted and unrejected, still sitting in the candidates folder, because the promotion rubric routes any unresolved contradiction with already-ratified Core content to the operator rather than letting the reviewing process resolve it unilaterally. The recommendation reached during this review is that all seven should simply be rejected, since the underlying claim that the GEO Suite's Knowledge Core is unbuilt future work was independently verified to be false rather than merely contested, but this decision was left open for the operator's explicit confirmation rather than being acted on directly.
