# A candidate note that fails review is never deleted, only status-flipped in place with a dated reason, so the judgment itself remains a visible record

## Body

A candidate note that fails the promotion review is never deleted from the candidates folder. Instead its status field is changed in place to reflect the rejection, along with a dated line recording the specific reason the reviewer rejected it, so the judgment itself remains a visible, reviewable record rather than disappearing along with the rejected content. This rule was applied consistently across every rejected candidate in this session's full backlog review.
