# Whether to modify the standard end-of-session closeout process to automatically archive a session's raw transcript, rather than requiring it be done manually as this session had to, is an open next-action question

## Body

An open question and candidate next action identified but not implemented during this session is whether to modify the repository's standard end-of-session closeout process so that it automatically calls the existing raw-transcript archive-writing function as a normal step, rather than requiring a session to remember to do this manually as happened in this session only because the operator explicitly asked for it. Wiring this in as a standing, automatic step would let future sessions' notes comply with the real archive-provenance schema without needing the candidate-note grandfather allowlist extended again each time.
