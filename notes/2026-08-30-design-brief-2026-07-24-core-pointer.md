# Design brief 2026-07-24 (Modern Minimalist Dashboard & Product UI) — retroactive Core pointer

## Body

First of six weekly Oluwole design-research briefs, none of which had any Knowledge Core
representation before 2026-08-30 (see
`2026-08-30-six-oluwole-design-briefs-piled-up-with-zero-folded-into-design-principles`). This
brief predates the "Recommended next steps for Amaya" convention (introduced 08-08), so it has no
explicit recommendations block — its findings read as direct rule refinements instead. Synthesis:
cut color toward monochrome with one accent (Linear/Vercel both moved this direction); adopt a
Major Second (1.125) type ratio on a 14px base; apply aggressive negative letter-spacing on
display sizes only; treat 600-weight as sufficient emphasis, skip 700; prefer shadow-as-border
over hard 1px lines; lead metric cards with 3–4 primary numbers (number + trend + sparkline);
keep semantic color to success/danger only; foreground one health signal with progressive
disclosure to detail; enforce the existing 4px spacing scale more strictly; require loading/empty/
error states per component, matched to a skeleton-vs-spinner-vs-"updating" decision rule; and
standardize filter chips plus typed table cells (currency/status/trend). None of these have been
applied to `DESIGN_PRINCIPLES.md` as of 2026-08-30 — see the parent finding note for the
verification. Full findings, each independently cited: `references/design/briefs/design-brief-2026-07-24.md`.
