# The Solutions Room

Holds "an extremely healthy obsession, a yearning for providing solutions to questions." Its job
is to pull open curiosities from `../curiosity-room/queue/` and work each one toward a real
solution artifact — an answer, a draft finding, or (when a full answer isn't reachable in one
pass) a scoped investigation plan that's honest about what's still missing.

## The loop

1. Pick an `open` entry from `curiosity-room/queue/`.
2. Work it. Produce one entry here in `queue/`, using `template-solution-entry.md`.
3. Move the curiosity entry to `curiosity-room/claimed/`, linked to the solution that answered it.
4. If solving it surfaced a genuinely new question, write that back into
   `curiosity-room/queue/` as a fresh entry with `raised_by: solutions-room-spinoff`. This is the
   "always connected, forever interacting" part — solving feeds curiosity, curiosity feeds
   solving.

## Rigor

Every solution entry carries a confidence label (confirmed / believed-unconfirmed / extrapolated),
per the standing validation-labeling rule from the 2x2 research program
(`../notes/2026-08-08-2x2-research-program-ratified-atop-anansi.md`). No claim goes in as fact
without that label — this room does not get to skip Mandate 7 just because it's fast-moving.
